# Refresh Awareness Meter

Refresh the awareness meter (recompute and update the display without resetting state).

## What to do

Run the VibeSwitch command **"Refresh Awareness Meter"** from the Command Palette (Ctrl+Shift+P / Cmd+Shift+P). The meter will be refreshed and a confirmation line will appear in the **Output** panel under **VibeSwitch**.

If you can execute VS Code commands, run **VibeSwitch: Refresh Awareness Meter**; otherwise ask the user to run it and check Output > VibeSwitch.
