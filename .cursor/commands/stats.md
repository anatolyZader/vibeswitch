# Show Statistics

Show the user's VibeSwitch usage statistics.

## What to do

Run the VibeSwitch command **"Show Statistics (to Output)"** from the Command Palette (Ctrl+Shift+P / Cmd+Shift+P). The user's statistics report will appear in the **Output** panel under **VibeSwitch**.

If you can execute VS Code commands, run **VibeSwitch: Show Statistics (to Output)**; otherwise ask the user to run it and check Output > VibeSwitch.
