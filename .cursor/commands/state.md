# Show State

Show the current state of antipatterns meters, debt, unreviewed changes, and unopened files.

## What to do

Run the VibeSwitch command **"Show State"** from the Command Palette (Ctrl+Shift+P / Cmd+Shift+P). The result will appear in the **Output** panel under **VibeSwitch** (antipatterns meters, debt, unreviewed changes, unopened files).

If you can execute VS Code commands, run it; otherwise ask the user to run **VibeSwitch: Show State** and check Output > VibeSwitch.
