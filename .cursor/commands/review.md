# Verbal Review

Get a short verbal review of the user's current vibe/antipatterns behavior and state.

## What to do

Run the VibeSwitch command **"Verbal Review (Antipatterns / State)"** from the Command Palette (Ctrl+Shift+P / Cmd+Shift+P). A short verbal review of the current awareness state, debt, and antipattern highlights will appear in the **Output** panel under **VibeSwitch**.

If you can execute VS Code commands, run **VibeSwitch: Verbal Review (Antipatterns / State)**; otherwise ask the user to run it and check Output > VibeSwitch.
